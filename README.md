# How To Open (Intellij IDEA)
1. Open project in Intellij IDEA
2. Run Main.java

# Libraries Used
1. JLayer - https://mvnrepository.com/artifact/javazoom/jlayer/1.0.1
2. MP3SPI - https://mvnrepository.com/artifact/com.googlecode.soundlibs/mp3spi/1.9.5-1
3. Tritonus Share - https://mvnrepository.com/artifact/com.googlecode.soundlibs/tritonus-share/0.3.7-1

Note: Software is under development.
